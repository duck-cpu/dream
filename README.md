# Dream

A Minecraft Forge mod centered around entering a Dream world while sleeping.

## Target

- Minecraft 1.20.1
- Forge 47.4.10
- Kotlin
- Kotlin for Forge 4.10.0

## Status

Early development / pre-alpha.

Current functionality includes:

- Dream entry through valid vanilla sleeping
- Custom Dream dimension
- Timed Dream sessions
- Persistent sessions across Save & Quit
- Return to the player's original bed
- Debug `/dream enter` and `/dream exit` commands

See `plan` for the development roadmap.
